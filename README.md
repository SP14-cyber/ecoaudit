# ecoaudit

## 💡 Inspiration
We are sick of brands lying to us. Walk down any store aisle or scroll through any shopping app, and you are bombarded with terms like "all-natural," "eco-friendly," "consciously sourced," and "carbon-neutral." Most of it is completely unregulated marketing jargon designed to exploit people who want to buy responsibly. The advertising laws around these terms are incredibly weak, and unless you have a degree in environmental science, it is almost impossible to tell what is a real sustainable practice and what is just corporate greenwashing. We built EcoAudit to completely change this dynamic. Instead of making another polite chatbot that simply answers basic questions, we wanted to build an active, adversarial tool. We wanted to give students and consumers a way to actively audit corporate claims, dissect massive sustainability reports, and call out greenwashing using real data and established environmental frameworks.

## What it does
EcoAudit: The AI Greenwashing Whistleblower shifts the user from a passive question-asker into a rigorous corporate auditor. The application handles a highly specific, multi-stage analytical workflow beginning with massive document text parsing. Users paste marketing ad copy, text from a product label, or content from a multi-page corporate sustainability report. The application completely eliminates vibes-based grading by evaluating the text strictly against the Federal Trade Commission Green Guides and TerraChoice’s Seven Sins of Greenwashing. It strips away the marketing fluff and renders a detailed, color-coded environmental scorecard alongside a quantified Greenwashing Risk Level. If a user thinks the system is being too harsh or missing crucial context, they can engage the interactive debate mode. EcoAudit will defend its stance using logic and regulatory data, but if the user brings real, verifiable evidence, the system adaptively updates its grade on the fly. Once greenwashing is exposed, the app automatically transitions from an analytical engine into an advocacy tool by compiling the failures into a professional corporate call-out letter template that users can send to the brand to demand transparency.

## How we built it
We focused on build speed, complete reliability, and absolute transparency to optimize our intense hackathon timeline. The entire frontend framework is engineered as a full Next.js App Router project utilizing React and Tailwind CSS for a clean, highly scannability-optimized user interface. To ensure maximum stability, zero operating costs, and complete user data privacy, EcoAudit runs its framework evaluations entirely client-side using a deterministic rule-based engine mapped directly to the FTC Green Guides and TerraChoice frameworks. This deliberate engineering choice eliminates server latency, prevents API rate-limiting bottlenecks, and guarantees that the tool can remain completely free and open-source for student consumers globally without requiring heavy corporate backend budgets. To calculate the final Greenwashing Index, the app compiles individual infractions against a weighted loss function, which can be mathematically represented as:

$$\text{Greenwashing Index} = 100 - \sum_{i=1}^{n} (w_i \cdot S_i)$$

In this equation, $w_i$ represents the severity weight assigned to a specific framework violation, and $S_i$ is a binary indicator where $S_i = 1$ if the specific sin of greenwashing is detected, and $S_i = 0$ if the claim passes compliance checks.

## Challenges we faced
Our absolute biggest technical roadblock was overcoming algorithmic gullibility during early prototyping. In our earliest builds, simple string searches would falsely clear deceptive text if a corporate report cleverly hid buzzwords inside dense paragraphs. For instance, if a corporate text stated that their packaging naturally degrades over time, basic text logic would struggle to weigh the context accurately. We fixed this by implementing strict negative constraint guardrails into our matching logic. We programmed the engine to treat every environmental claim as guilty until proven innocent. The system bars a product from achieving a high passing grade unless the text explicitly contains verifiable, independent third-party benchmarks like USDA Organic, Forest Stewardship Council, Fair Trade Certified, Energy Star, or Cradle to Cradle. If those formal benchmarks are absent from the document, the grade drops immediately, forcing the system to maintain strict algorithmic skepticism.

## Accomplishments that we're proud of
We successfully built a functional, highly defensive tool that turns software into an active weapon for consumer advocacy. We are proud that our app handles complex text parsing—reading raw text inputs—and successfully translates dense corporate compliance metrics into a clear, actionable game plan for everyday consumers. We managed to take an abstract, highly complex legal and ecological issue and distill it into a simple, high-utility, student-friendly web application that provides immediate civic utility with zero external server dependencies.

## What we learned
We learned the exact legal loopholes corporations use to dodge advertising laws and manipulate public perception through structural phrasing. On the technical side, we mastered how to build a responsive client-side evaluation architecture, how to handle state transitions between the input, scorecard, and debate modules in React without a database layer, and how to structure a completely static Next.js project optimized for immediate, zero-config hosting deployment.

## What's next for EcoAudit
The long-term roadmap scales EcoAudit from an interactive web prototype into a ubiquitous mobile consumer tool. We plan to integrate direct barcode scanning and OCR lookups so users can take a photo of a physical packaging layout in a store aisle and instantly extract text for an on-the-spot audit. We also aim to build web scrapers to dynamically ingest localized municipal waste regulations based on the user's real-time zip code, translating highly confusing local sorting laws into absolute certainty. Finally, we want to launch a crowdsourced public ledger database where all student-audited products and their corresponding framework scorecards are saved openly to establish a community-driven baseline for brand accountability.
