# EcoAudit: The AI Greenwashing Whistleblower

EcoAudit is a free, citizen-science web application designed to expose deceptive environmental marketing. Walk down any store aisle today, and almost every product claims to be "all-natural," "eco-friendly," or "carbon-neutral." Most of these terms are completely unregulated marketing tricks meant to exploit well-intentioned shoppers. Unless you have an advanced degree in environmental policy, it is nearly impossible to tell what is a legitimate sustainable practice and what is just corporate greenwashing. EcoAudit changes this dynamic by putting an objective, framework-backed auditing tool directly into the hands of everyday consumers and student advocates.

## How EcoAudit Works

The application operates as a transparent, interactive environmental compliance platform. Users can paste text from a marketing advertisement, an ingredient label, or an entire corporate sustainability report directly into the dashboard. EcoAudit completely removes personal bias from the equation by grading the input text strictly against established consumer protection frameworks, specifically the Federal Trade Commission Green Guides and TerraChoice’s Seven Sins of Greenwashing. The app strips away the marketing fluff and outputs a clear, color-coded A through F scorecard along with an explicit Greenwashing Risk Level.

If you believe the system graded a product too harshly, you can push back using the interactive Debate Mode. The system will intelligently defend its ecological stance using regulatory logic, but it will dynamically upgrade the product's grade if you provide a verifiable third-party certification code. Once greenwashing is successfully exposed, EcoAudit shifts from an analytical tool into an activism weapon. It automatically generates a polite but firm corporate call-out letter citing the exact framework violations. You can immediately copy this text, send it to the brand's public relations team, and demand true environmental accountability.

## The Technology Behind the Tool

EcoAudit is engineered using Next.js, React, and Tailwind CSS to ensure a fast, highly scannable, and modern user experience. To guarantee absolute user data privacy, zero operating costs, and complete protection against server down-time, EcoAudit runs its entire evaluation process directly inside your web browser. This serverless, client-side design choice means the app requires no external API keys, does not track your personal search history, and will remain 100% free, lightweight, and open-source for consumers globally forever.

## Getting Started Locally

You can launch EcoAudit on your computer and start auditing products in less than two minutes. Because the engine runs entirely client-side, you do not need to configure any complicated databases or secret environment keys. Simply open your computer's terminal, clone this repository to your local machine, and run the installation commands to boot up the application:

npm install
npm run dev

Once the compiler finishes running, open your web browser and navigate to http://localhost:3000 to instantly access your local auditing dashboard.

## Our Vision for the Future

We view this hackathon MVP as the foundation for a much larger grassroots environmental movement. Our long-term roadmap includes integrating mobile camera capabilities so users can scan product barcodes or snap photos of packaging layouts directly in grocery aisles for instantaneous point-of-sale audits. We also plan to build automated data tools to dynamically match municipal recycling rules against a user's zip code, clearing up confusion about local sorting laws. Finally, we aim to launch a crowdsourced public database where all audited products and their corresponding F-grades are saved openly, building a community-driven baseline for global brand transparency.
